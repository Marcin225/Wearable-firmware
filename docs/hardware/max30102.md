# MAX30102 Optical Sensor

The **MAX30102** is the optical sensor used to acquire the photoplethysmography (PPG) signals required for heart-rate and SpO2 estimation.

The sensor operates using two optical channels:

- **IR** – used as the main PPG signal for heart-rate estimation and finger detection,
- **RED** – used together with IR for SpO2 estimation.

The MAX30102 communicates with the ESP32-C3 through I2C using the 7-bit address `0x57`.

## Sensor Configuration

The sensor is configured for simultaneous RED and IR acquisition with the following parameters:

| Parameter | Configuration |
| :--- | :--- |
| Sampling rate | **100 Hz** |
| ADC range | **4096 nA** |
| LED pulse width | **411 µs** |
| ADC resolution | **18 bit** |
| RED LED current | **6.2 mA** |
| IR LED current | **6.2 mA** |
| Operating mode | RED + IR |
| FIFO rollover | Enabled |
| FIFO almost-full level | **28 unread samples** |

The SpO2 configuration register is set to `0x27`, which configures the 4096 nA ADC range, 100 Hz sampling rate and 411 µs LED pulse width.

Both LED current registers are set to `0x1F`, corresponding to approximately **6.2 mA** for the RED and IR LEDs.

## FIFO Acquisition

The MAX30102 contains a 32-sample hardware FIFO used to store measurements before they are transferred to the ESP32-C3.

FIFO rollover is enabled and the almost-full threshold is configured so that an interrupt is generated when approximately **28 samples** are waiting to be read.

At a sampling rate of 100 Hz, this corresponds to approximately:

```text
28 samples / 100 samples/s ≈ 280 ms
```

Instead of reading one sample every 10 ms, the ESP32-C3 can therefore remain inactive between acquisitions and transfer multiple samples at once.

When the FIFO almost-full interrupt occurs:

- the interrupt handler wakes `vCollectAndFilterDataTask`,
- the FIFO read and write pointers are checked,
- all available RED and IR samples are transferred over I2C,
- the samples are stored in the driver's local ring buffer.

The local ring buffer can store up to 256 RED and IR samples.

Each sensor sample consists of:

```c
struct MaxSample {
    uint32_t Red;
    uint32_t Ir;
};
```

The MAX30102 provides each channel as a 3-byte value. Only the lower 18 bits contain measurement data and are retained by the driver.

## FIFO Almost-Full Interrupt

The FIFO almost-full interrupt wakes `vCollectAndFilterDataTask` when a new batch of samples is ready to be read.

## Finger Detection

Finger presence is detected directly from the raw IR signal.

The firmware uses:

```c
FINGER_IR_THRESHOLD = 50000;
```

A raw IR value above this threshold is treated as finger presence.

If the IR signal falls below the threshold, the current continuous measurement session is interrupted. A prolonged absence of the finger can eventually cause the device to enter deep sleep.

## Role in Heart-Rate Estimation

The IR channel is the main optical signal used for heart-rate estimation.

After acquisition, the IR samples are preprocessed and included in the rolling processing window used by the FFT-based heart-rate algorithm.

The RED channel is not required for the main HR estimation path.

## Role in SpO2 Estimation

SpO2 estimation uses both the IR and RED channels.

The algorithm uses:

- the AC component of the IR signal,
- the AC component of the RED signal,
- the DC level of the raw IR signal,
- the DC level of the raw RED signal.

The RED and IR relationship is then used by the SpO2 algorithm to estimate oxygen saturation.

Raw RED and IR samples are therefore also accumulated before filtering to maintain the DC values required for the calculation.

## Shutdown Mode

The MAX30102 is placed into shutdown mode when optical measurements are not required.

Shutdown is entered by setting the `SHDN` bit in the mode configuration register:

```c
writeRegister(MAX30102_MODE_CONFIGURATION, 0x80);
```

When measurements are required again, the sensor is restored to RED + IR operation:

```c
writeRegister(MAX30102_MODE_CONFIGURATION, 0x03);
```

Shutdown mode is used during deep sleep and between periodic finger checks in CHECK mode to reduce power consumption.

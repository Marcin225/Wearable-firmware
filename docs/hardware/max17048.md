# MAX17048 Battery Fuel Gauge

The MAX17048 is used to monitor the Li-Po battery state of charge and provide the battery percentage reported by the firmware.

The sensor communicates with the ESP32-C3 through I2C.

## Configuration

| Parameter | Value |
| :--- | :--- |
| I2C address | `0x36` |
| SOC register | `0x04` |
| CONFIG register | `0x0C` |
| CMD register | `0xFE` |
| Reset command | `0x5400` |

The MAX17048 uses 16-bit register reads and writes. Register values are transferred with the most significant byte first.

## Initialization

During initialization, the driver first checks whether the device responds at the expected I2C address.

If the device is detected, the MAX17048 is reset using:

```text
CMD register = 0x5400
```

## Battery Percentage

Battery state of charge is read from the SOC register.

The register contains:

- the integer percentage in the most significant byte,
- the fractional part in the least significant byte with a resolution of 1/256 %.

The firmware currently uses only the integer part:

```cpp
uint8_t batteryPercent = socRaw >> 8;
```

The returned value therefore represents the battery state of charge as an integer percentage. If the I2C read fails, `readBatteryPercent()` returns `-1`.

## Sleep Mode

The MAX17048 can be placed into sleep mode to reduce power consumption.

Sleep mode is enabled by setting bit 7 of the CONFIG register:

```cpp
config |= 0x0080;
```

The existing configuration value is preserved and only the sleep bit is modified.

## Wake-Up

Normal operation is restored by clearing bit 7 of the CONFIG register:

```cpp
config &= ~0x0080;
```

After wake-up, the device can continue reporting the battery state of charge.

## Driver Interface

The driver provides the following main operations:

| Function | Description |
| :--- | :--- |
| `begin()` | Checks communication with the device and performs a reset |
| `readBatteryPercent()` | Returns the integer battery state of charge |
| `sleep()` | Places the fuel gauge into sleep mode |
| `wakeUp()` | Restores normal operation |
